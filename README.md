## Workflow & Communication Rules
* **Branching & PRs:** Every team member works on a dedicated feature branch (`feature/<name>-<section>`) from their own GitHub account and merges to `main` via a Pull Request reviewed by at least one teammate.
* **Communication Cadence:** The team holds twice-weekly synchronous check-ins via Microsoft Teams/Discord and daily asynchronous status updates in the group chat.
